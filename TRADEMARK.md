# Name and icon policy

"VoiceDraft" and the VoiceDraft icon identify builds published by the project maintainer. The name and icon are currently unregistered marks. This policy is separate from the AGPL-3.0 license, which covers the code only and grants no rights in the name or icon.

## Allowed

- Redistributing an unmodified official release with its name and icon intact.
- Saying that your project is "based on VoiceDraft" or "compatible with VoiceDraft sync", truthfully and without implying endorsement.
- Referring to VoiceDraft by name in reviews, articles and documentation.

## Not allowed

- Using the name or icon for a fork, a modified build, or a service that is not run by the maintainer. Forks and modified builds must choose a different name and a different icon.
- Using the name or icon in a way that suggests the maintainer made, approved or supports your build.
- Registering the name, the icon or a confusingly similar one as a trademark, domain name or app store listing.

## Questions

Ask the maintainer through a GitHub issue if you are unsure whether a use is acceptable.
